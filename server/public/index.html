How to Deploy on Vercel for Free

100% Free Tier
1

Push to GitHub or Use Vercel CLI

Push this folder to your GitHub repo, or run npx vercel inside the server folder.

2

Enable Vercel Blob Storage

In your Vercel Dashboard, go to Storage → Click Create Database → Select Blob → Click Create.

3

Connect Blob Token

Click Quickstart / Settings in your Blob store, copy BLOB_READ_WRITE_TOKEN, and add it to your Vercel Project Environment Variables!

REST API Endpoints for Integration (WinLocker, scripts, or apps):

// Upload File
POST /api/storage/upload (multipart/form-data: 'files')

// Get Storage Stats & Quota
GET /api/storage/stats

// List All Files
GET /api/storage/files?category=all&search=vault

// Delete File
DELETE /api/storage/delete?url=<file_url>
